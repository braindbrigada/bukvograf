Политика конфиденциальности БуквоГраф

Дата редакции: 18 ноября 2026 года.

Разработчик: braindbrigada

Контакт для вопросов о конфиденциальности: braindbrigada@gmail.com

1. Назначение

БуквоГраф — расширение для исправления раскладки, перевода, коррекции и улучшения выделенного пользователем текста в браузере. Эта политика описывает обработку данных расширением версии 1.2.4.

2. Какие данные обрабатываются

  • Выделенный текст. Только когда пользователь запускает «Перевести», «Исправить ошибки» или «Улучшить текст», расширение считывает выделенный текст из поддерживаемого редактируемого поля и передаёт его в OpenAI API для выполнения выбранной функции. Если выделенный текст содержит персональные, конфиденциальные или другие чувствительные сведения, они могут оказаться в запросе. Не запускайте AI-функции для текстов, которыми не хотите делиться с OpenAI.
  • API-ключ OpenAI. Пользователь вводит собственный API-ключ. Он сохраняется в chrome.storage.local на устройстве пользователя и передаётся только на https://api.openai.com/ при запросах к API (в заголовке авторизации). Разработчику ключ автоматически не отправляется.
  • Настройки. Выбранная модель, список доступных моделей, языковая пара, стиль и параметр «Человечность» сохраняются в chrome.storage.local для работы функций.

3. Что не передаётся

Функция «Сменить раскладку» преобразует текст локально и не требует сетевого запроса. Расширение не использует постоянное считывание содержимого вкладок и не отслеживает ввод в фоне. Парольные поля исключаются из обработки. Код БуквоГраф не отправляет историю посещённых сайтов, URL страницы и полный текст страницы в OpenAI при выполнении обычных AI-действий; передаётся выбранный фрагмент и инструкция, описывающая действие. При получении списка моделей отправляется API-ключ, но не текст страницы.

4. Получатели и цели передачи

При вызове AI-функции запрос направляется напрямую из браузера пользователя в OpenAI API по HTTPS. Разработчик БуквоГраф не использует собственный промежуточный сервер для обработки этих запросов. OpenAI является сторонним поставщиком обработки; его правила обработки и возможного хранения данных определяются политиками и условиями OpenAI: Политика OpenAI и Обработка данных API.

Для запросов Responses API БуквоГраф передаёт параметр store: false. Это не означает гарантированного отсутствия любого хранения данных на стороне OpenAI: условия обработки и сроков хранения следует проверять по актуальной документации OpenAI.

5. Хранение и удаление

Расширение не сохраняет историю обработанных текстов в собственном журнале. Ключ и настройки хранятся локально до их изменения/очистки пользователем или удаления данных расширения. Удаление расширения обычно удаляет его локальные данные в профиле браузера. Пользователь может заменить API-ключ в настройках и управлять своим ключом через аккаунт OpenAI. БуквоГраф не управляет хранением данных OpenAI.

6. Платежи и донат

БуквоГраф не обрабатывает номера банковских карт и не осуществляет платежи внутри расширения. В настройках может отображаться QR-код добровольной поддержки; при сканировании пользователь переходит к операции в отдельном банковском приложении. Банковские данные не передаются БуквоГрафом. Донат не открывает дополнительные функции. Вызовы OpenAI API могут тарифицироваться OpenAI по условиям аккаунта пользователя.

7. Реклама, продажа данных и ограничения использования

БуквоГраф не содержит рекламных трекеров, не продаёт пользовательские данные и не использует выделенный текст для рекламного профилирования. Доступ к данным ограничивается функциями, которые пользователь сам запускает. Использование данных соответствует применимым требованиям Chrome Web Store User Data Policy и Limited Use: данные используются только для описанной функциональности расширения и связанных с ней операций.

8. Обновления политики и связь

При существенных изменениях передачи или обработки данных политика будет обновлена и пользователи получат соответствующее уведомление. Для вопросов или запросов, касающихся работы расширения, пишите: braindbrigada@gmail.com.
